# OpenTransmit

免费开源的 macOS 双栏文件传输应用。使用系统原生组件，以拖拽复制、清晰的冲突处理和可恢复工作区为核心。

> 当前为 **0.2 SFTP 开发预览版**：支持本地↔SFTP、SFTP↔SFTP（经本机中转）文件及目录传输。FTP/FTPS 和应用内 SMB 客户端尚未接入；已挂载的 SMB 共享仍可作为本地目录选择。已完成本机双 SFTP 服务端互通测试，真实云服务器兼容性待联调。

## 已实现

- SwiftUI 窗口与 AppKit NSTableView 双栏文件列表、可调整分栏和服务器/工作区侧栏。
- 每栏通过统一的“选择位置…”菜单选择本地目录、已挂载共享或已保存服务器；支持双击进入子目录、返回、上级目录、刷新和显示隐藏文件。
- 每栏提供复制、粘贴按钮和键盘/右键操作；本地删除支持多选，二次确认后移入废纸篓。远程删除暂不开放。
- 每栏可连接独立 SFTP 服务器，支持上传、下载和通过本机分块中转；内容块大小 64 KiB，不将整份文件读入内存。
- 密码或 OpenSSH 私钥认证；首次连接确认 SHA256 主机指纹，已信任主机的公钥变化时拒绝连接。
- 文件夹优先、名称自然排序；展示大小和修改时间；支持多选。
- 双栏拖拽复制，也可通过“复制到另一栏”按钮或右键菜单复制选中项目。
- 支持接收 Finder 文件 URL 拖放；目的地为接收栏当前目录。
- 同名文件询问：替换、保留两者、跳过、取消；可以将选择应用到当前队列后续冲突。
- 同名目录合并，保留目标目录独有项目。文件与目录类型不同时禁止替换，可保留两者或跳过。
- 后台串行传输队列，展示已复制字节、状态和错误；支持取消全部、失败重试和清除记录。
- 保存 SFTP、FTP、FTPS、SMB 服务器的名称、主机、端口、用户名和默认路径；可删除资料。
- 保存左右目录为命名工作区，通过安全作用域书签跨启动恢复；打开工作区不会自动传输。
- App Sandbox 与用户选择文件读写授权，不要求整盘访问权限。

## 运行

当前应用 target 的 Deployment Target 为 macOS 27.0（项目级默认值为 14.0），在 Xcode 27 beta 上构建验证。运行请以 target 设置为准；本次保留现有 target 配置，尚未验证旧版 macOS。

在 Xcode 中打开 `OpenTransmit.xcodeproj`，选择 **OpenTransmit / My Mac**，运行即可。本地脚本采用 ad-hoc 签名，不需要配置开发团队：

```bash
./script/build_and_run.sh
```

Codex 项目 Run 按钮也指向此脚本。脚本运行前会停止已有的 OpenTransmit 进程，请先完成或取消传输。

```bash
./script/build_and_run.sh --build   # 只编译
./script/build_and_run.sh --verify  # 编译、启动并检查进程
./script/build_and_run.sh --debug   # LLDB 启动
./script/build_and_run.sh --logs    # 启动并查看系统日志
./script/test.sh                   # 独立文件引擎回归测试
```

构建产物位于 `.build/Build/Products/Debug/OpenTransmit.app`。

## 使用

1. 分别点击左右栏的“选择位置…” → “本地目录或已挂载共享…”，授予目录访问权限。
2. 双击文件夹进入；选中文件或目录，拖到另一栏，或点击“复制到另一栏”。拖拽和复制按钮不会删除源文件。使用单栏“删除”按钮会在确认后将所选项目移到废纸篓。
3. 遇到冲突时比较双方路径、大小和修改时间，再决定替换、保留两者或跳过。
4. 在底部队列查看结果。取消会停止后续工作，但已完成的文件保留。
5. 点击工具栏“保存工作区”，为当前左右目录命名。之后从侧栏恢复。
6. 通过“添加服务器”保存 SFTP 主机、端口、用户名和默认目录，然后按下面步骤连接。

## SFTP 连接与服务器间传输

1. 添加服务器，协议选择 **SFTP**，填写主机（不包含 `sftp://`）、端口、用户名和起始目录。
2. 在空白栏或单栏顶部的“选择位置…”菜单中选择服务器，或右键侧栏服务器选择“连接到左栏/右栏”。
3. 在连接弹窗输入密码，或选择 OpenSSH 格式的 Ed25519 / RSA 私钥；加密私钥另填口令。密码和私钥不写入服务器资料或日志，也暂不保存到钥匙串。
4. 第一次连接会拒绝未信任主机并展示 SHA256 指纹。通过云控制台核对后点击“信任此主机并连接”；随后才完成认证。已信任主机公钥变化时拒绝连接，不提供跳过验证按钮。
5. 一边本地、一边远程时即为上传/下载；两边各连一台 SFTP 服务器即为服务器间传输。选中项目后点击“复制到另一栏”、使用应用内复制粘贴或拖拽。
6. 通过单栏“选择位置…”菜单中的“断开连接”结束会话；传输中暂时不能主动断开。连接断开或失败后可重新连接，再重试任务。旧任务持有旧会话位置，重新连接后请重新选择文件发起传输。

服务器间传输的路径为 `服务器 A → 本机内存块 → 服务器 B`，没有要求 A 能访问 B，也没有把认证凭据转交给另一台服务器。吞吐受本机与两端网络限制；队列中的字节数表示复制的有效内容量，不把中转的收发各算一遍。

两栏可以连接同一服务器的不同目录。使用相同主机名、端口和用户名建立的不同会话会共同检查自身/子目录复制；不要用不同 DNS 别名或不同账户将同一实际目录伪装成不同端点进行循环复制。

### 当前远程限制

- 远程删除不套用本地废纸篓规则，暂时禁用；远程文件不支持直接拖出到 Finder（可先下载到本地）。
- 工作区目前只保存本地目录组合，任一栏为远程时“保存工作区”暂不可用。
- 密码和私钥仅保留在当前连接所需的内存中；切回本地目录会保留旧会话以免破坏队列，退出应用会释放连接。尚未实现 SSH agent、跳板机、键盘交互认证及自动重连。
- Ed25519 认证已通过互通测试。RSA 的可用性受服务器签名算法策略影响；不自动开启弱算法来绕过服务器限制。
- 连接、SSH 握手、SFTP 子通道和数据请求均有超时限制；数据请求超过约 30 秒没有完成会关闭该子通道。取消会关闭当前子通道并尝试清理临时文件。
- 符号链接和无法识别的特殊文件类型拒绝传输；目录递归最多 128 层。不支持权限/ACL/扩展属性复制、断点续传及同步删除。

## 单栏操作与快捷键

先点击目标栏的文件列表，使其获得键盘焦点。左右栏保留独立选择，快捷键只操作获得焦点的一栏；文本输入框仍使用系统编辑快捷键。

| 操作 | 快捷键 |
| --- | --- |
| 复制所选文件到系统剪贴板 | `⌘C` |
| 粘贴到当前栏目录 | `⌘V` |
| 全选当前列表 | `⌘A` |
| 删除所选项目（确认后移到废纸篓） | `⌘⌫` |
| 连续选择 / 不连续多选 | `Shift` 点击 / `⌘` 点击 |

复制粘贴可在同栏或跨栏使用，也可接收 Finder 复制的文件 URL。在源目录粘贴会自动生成带“副本”后缀的新项目，保留原文件和目录。粘贴到其他目录时仍按原有冲突规则询问。

删除确认展示本次所选数量和文件名（超过 8 项显示前 8 项及剩余数量），默认按钮为取消。批量删除中的单项失败不会阻止其余项目，结束后显示失败明细并刷新两栏。若磁盘或网络共享不支持废纸篓，会报告失败，绝不自动永久删除。传输进行时暂时禁用删除，删除执行期间暂停接受新的复制任务。

## 数据与复制语义

服务器资料和工作区书签以 JSON 编码存入应用的 UserDefaults。书签失效、目录移动或权限变化时，重新选择目录并保存工作区。目录授权在应用会话期间保持，以免切换目录中断正在进行的复制。

本地目标普通文件先复制到目标目录中的随机 `.opentransmit-*.partial` 临时文件，写入完成后再提交；替换使用同一文件系统内的原子重命名。正常失败或取消会清理当前临时文件。强制退出或断电可能留下临时文件。

远程目标也先上传到同目录 `.opentransmit-*.partial`。SFTP v3 的通用重命名不能保证原子覆盖，因此确认替换后先把旧文件重命名为 `.opentransmit-*.backup`，再提交新文件；提交失败尝试回滚。断网或回滚失败时备份可能保留，错误信息会提示备份位置。正常取消会尝试清理临时文件，连接已断开时清理可能失败；不要在确认恢复前删除备份。目标目录应避免被其他程序同时修改。

目录逐个文件复制，**不是整个目录的原子事务**：取消或失败时已经完成的文件和创建的目录保留。重试从头执行，可能再次询问冲突；不支持断点续传。目标目录在复制期间应避免被其他程序重命名或修改。

复制当前拒绝符号链接和特殊文件，防止递归逃逸和意外复制；普通跨栏复制不能指向自身或其子目录；剪贴板原目录粘贴会生成旁侧副本。当前复制普通文件内容，不保证保留 POSIX 权限、扩展属性、资源叉等元数据，不适合作为备份工具。

## 代码结构

```text
OpenTransmit/
  App/          应用入口
  Models/       文件、服务器、工作区和传输模型
  Stores/       双栏状态、资料持久化、队列与冲突决策
  Services/     本地 I/O、端点中立传输引擎、SFTP 会话/流和主机信任
  Views/        双栏、侧栏、传输队列及原生弹窗
Tests/          使用临时目录的文件引擎回归测试
script/         构建、运行和测试入口
```

本地复制继续使用 `LocalFileService`。包含远程端点的任务由 `EndpointTransferEngine` 通过 `TransferEndpoint` / `TransferReader` / `TransferWriter` 分块处理；`SFTPRegistry` 管理会话并路由本地和远程 I/O。UI 状态由 MainActor 维护。应用内远程 URL 使用会话 ID，不包含密码或私钥。

### SFTP 集成测试

2026-09-11 已在 App 界面验证私钥选择、首次主机指纹确认、远程目录显示、按钮上传、下载重名提示及保留副本；上传与下载副本通过字节一致性检查。自动化集成测试覆盖服务器间中转，真实云服务器兼容性仍待联调。

```bash
# 仅首次准备测试环境；不加入 App 运行时依赖
python3 -m venv .build/sftp-test-env
.build/sftp-test-env/bin/python -m pip install paramiko==4.0.0
./script/build_and_run.sh --build
./script/test_sftp.sh
```

脚本使用两个只绑定 `127.0.0.1` 的临时 Paramiko SFTP 服务端和一次性密钥，所有读写限制在临时目录，结束后关闭服务并清理。覆盖主机未信任/变化拒绝、错误密码、密码/Ed25519 认证、目录和空文件、中文/特殊字符文件名、150 项目录枚举、上传下载字节一致、服务器间中转、跳过/副本/覆盖、失败回滚、自身复制保护、权限失败、符号链接拒绝和取消清理。不会读取用户 SSH 配置或连接外部服务器。

真实云服务器联调请准备：地址、SFTP 端口、用户名、认证方式、专用读写测试目录，以及通过云控制台获取的主机 SHA256 指纹。密码/私钥在 App 中输入，不必发到聊天里。两台服务器可验证跨服务器传输；同一台的两个独立测试目录可先验证基本流程。

## 多工作区标签页

- 点击标签栏右侧的“+”或按 `⌘T` 新建一对独立的左右文件栏。
- 切换标签保留各自的目录、远程连接、选择、浏览历史及隐藏文件设置。传输队列由所有标签共享，切换标签不会停止任务。
- 点击标签上的关闭按钮关闭该工作区并断开其当前远程连接。传输或删除期间禁用关闭；关闭最后一个标签会自动创建空白工作区。
- 点击侧栏已保存的工作区会在新标签中恢复，不覆盖当前标签。标签本身暂不跨应用重启恢复；持久保存仍仅支持本地目录组合。
- 空白栏、栏顶部和侧栏均使用同一位置选择菜单，也可直接从菜单添加服务器。服务器右键“删除服务器配置”只移除保存配置，不删除远程文件。
