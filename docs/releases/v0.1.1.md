# OpenTransmit v0.1.1 测试版

OpenTransmit 是一款免费开源的原生 macOS 双栏文件传输工具。本次发布提供可直接下载安装的测试 DMG，欢迎尝鲜并反馈问题。

## 下载与安装

- 在本页 **Assets** 中下载 `OpenTransmit-v0.1.1.dmg`，无需下载 Source code 压缩包。
- 打开 DMG，将 `OpenTransmit.app` 拖入 `Applications`，然后从“应用程序”启动。
- 系统要求：**macOS 14.6 及以上**。
- 处理器：**Apple Silicon 与 Intel**，同一个通用安装包。
- 应用已使用 **Developer ID 签名并通过 Apple 公证**，公证票据已附加到应用。

首次访问本地目录时，请通过系统目录选择窗口授权。读取旧版保存的凭据时，钥匙串可能要求重新授权。

## 本次发布

- 应用版本统一为 `0.1.1`，构建号为 `1`。
- 启用 Hardened Runtime，完成用于直接分发的签名、公证与 DMG 打包。
- 已检查 DMG 完整性，并验证其中应用的签名、公证票据与 Gatekeeper 接受状态。

## 可体验的功能

以下是此版本包含的主要能力，并非全部为 v0.1.1 新增：

- **双栏文件管理**：目录导航、排序、当前目录名称筛选、新建目录、重命名与多选操作。
- **多协议传输**：本地、SFTP、FTP、显式 FTPS，以及通过 macOS 挂载的 SMB 共享；支持远程端点经本机中转。
- **传输队列与冲突处理**：进度显示、取消、重试，以及替换、保留两者、跳过等冲突选项。
- **任务恢复与续传**：本地和 SFTP 字节级续传；FTP/FTPS 续传取决于服务器能力，恢复前会校验源文件和已传内容。
- **多标签与工作区**：保存双栏位置、恢复远程目录，并设置默认传输方向。
- **目录差异预览**：按大小和修改时间比较，确认后执行单向复制，保留目标独有内容。
- **连接与凭据保护**：SFTP 主机指纹校验、FTPS 证书校验，以及可选的本机钥匙串密码保存。

## 测试范围与已知限制

这是测试版本，建议先使用可丢弃的测试文件验证自己的使用场景。签名与公证通过不代表所有系统和服务器组合均已验证。

- macOS 14.6、Intel Mac、真实 SMB 共享及更多服务器组合仍需实际兼容性测试。
- Finder 拖入、双栏多选拖拽和文件夹落点等交互仍需进一步验收；尚不支持远程文件拖出到 Finder。
- FTP 为明文协议；FTPS 仅支持显式 TLS，不支持隐式 FTPS/990，FTP/FTPS 目录列表要求 UTF-8 MLSD。
- 移动和目录传输并非整体事务；取消或失败不会撤销已经完成的文件操作。远程删除为永久删除。
- 尚未完整保留 ACL、扩展属性、资源叉等元数据，不适合作为完整备份工具。
- 目录比较不计算内容校验和；尚不支持自动同步、SSH agent、跳板机和自动重连。
