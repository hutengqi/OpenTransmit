<h1 align="center">OpenTransmit</h1>

<p align="center">原生 macOS 双栏文件传输工具 · 免费开源 · SFTP / FTP / FTPS / SMB</p>

## 项目介绍

OpenTransmit 是一款使用 SwiftUI 与 AppKit 构建的原生 macOS 文件传输应用。将本地目录和服务器目录放在左右两栏，通过拖拽、复制粘贴或传输按钮完成文件搬运；常用的目录组合可以保存为工作区，下次直接恢复。

适合本地项目上传、服务器文件下载，以及两台服务器之间的文件中转。图标是一台小面包车，呼应应用“搬运文件”的用途。

当前为 **0.3 多协议开发预览版**，运行要求为 **macOS 14 Sonoma 及以上**。旧系统及不同服务器的兼容性仍在验证中。

### 双栏浏览与文件管理

左右文件栏独立选择位置、浏览目录和选择文件，可以自由组合本地磁盘、已挂载共享与远程服务器。

- **快速导航**：点击列表顶部的 `..` 返回上一级；点击路径面包屑跨级跳转。面包屑旁的路径输入按钮支持绝对、相对目录路径，本地还支持 `~`。
- **排序与查找**：按名称、大小或修改时间排序，可切换升降序和文件夹优先。名称查找仅筛选当前目录，不递归搜索子目录或文件内容。
- **文件操作**：支持多选、复制粘贴、新建目录和单项重命名。新建和重命名遇到同名项目会拒绝操作，不主动覆盖。
- **隐藏文件**：每栏可独立切换显示，方便查看服务器配置目录。
- **删除确认**：本地及已挂载共享尝试移入废纸篓，不可用时报告错误；SFTP、FTP/FTPS 支持文件和非空目录的永久删除。单项和批量删除均需确认，批量失败会报告明细。

首次访问尚未授权的本地父目录时，macOS 会要求选择目录并授权。

### 支持的文件源

| 文件源 | 连接方式与能力 | 当前说明 |
| --- | --- | --- |
| 本地目录 | 系统目录选择、双栏浏览和文件操作 | 访问遵守 macOS 目录授权与文件权限 |
| SFTP | 密码或受支持的 OpenSSH 私钥认证，浏览、上传、下载及远程操作 | 首次连接核对主机指纹，已信任公钥变化时拒绝连接 |
| FTP | 密码认证、被动模式，优先 EPSV 并兼容 PASV | 密码与文件内容不加密，每次新建会话需确认明文风险 |
| FTPS | 显式 TLS 连接，通常使用 21 端口 | 强制加密控制及数据通道，校验证书链和主机名；暂不支持隐式 FTPS/990 |
| SMB | 在应用内发起 macOS 认证与共享选择，挂载后在文件栏使用 | `/` 用于选择共享，`/共享名` 直接连接；认证与挂载由系统管理 |

FTP/FTPS 当前要求服务器支持 UTF-8 MLSD 目录列表。SMB 共享可由 Finder 和其他应用共用，关闭标签不会卸载；使用完毕可在 Finder 中推出。SMB 加密与签名遵循系统及服务器策略。

### 传输、冲突与队列

选中文件后，可拖到另一栏、使用复制粘贴，或点击“复制到另一栏”。支持文件与目录的本地复制、本地与远程双向传输，以及 SFTP、FTP/FTPS 端点之间经本机中转的传输。已挂载 SMB 共享作为本地文件目录参与操作。

遇到同名项目时，可以选择 **替换、保留两者、跳过或取消**，也可将选择应用于后续冲突。同名目录合并，文件与目录类型不同时不允许替换。复制不会删除源文件。

传输队列显示任务状态、百分比、已处理/总字节数和平均处理速率，支持取消、重新执行和清理已结束任务。复制前先统计目录大小，提交成功前进度最多显示 99%。速率包含等待与提交耗时，不等同于瞬时网络速度。

未完成、失败或取消的任务可保存为恢复清单。重启应用后，在队列的“恢复任务”菜单选择重新执行；涉及远程服务器时先重新连接原服务器。任务从头复制并再次询问冲突，尚不支持字节级断点续传。“移除任务记录”不会删除文件。

SFTP 采用分块中转；涉及 FTP/FTPS 的传输会使用本机临时磁盘空间。目录传输失败或取消时，已经完成的文件和已创建的目录会保留。

### 服务器与工作区

- **保存和编辑服务器**：记录名称、协议、主机、端口、用户名及默认路径。右键服务器可编辑，修改用于后续连接，不改变正在使用的连接。
- **多标签工作区**：每个标签是一对独立文件栏，保留各自目录、选择与浏览历史，共享传输队列；切换标签不中断传输。
- **保存目录组合**：两栏选好位置后，右键标签选择“保存工作区…”，也可使用工具栏按钮。支持本地与远程、双远程组合。
- **自动恢复连接**：点击保存的工作区会新建标签。SFTP/FTPS 可使用已保存密码自动连接并进入记录目录；缺少凭据、需要授权或连接失败时提供手动入口。FTP 仍需明文确认，私钥认证仍需选择私钥文件。
- **默认传输方向**：保存时可选左 → 右、右 → 左或不设方向。设置后提供对应的“传输所选文件”按钮，拖拽和原有双栏复制仍按实际操作执行。

恢复工作区**不会自动传输文件**。SMB 工作区通过挂载目录书签恢复，需要共享已挂载且可访问；打开的标签暂不跨应用重启自动恢复。

### 凭据与连接安全

勾选“记住密码或私钥口令，下次自动填入”后，仅在连接成功时保存到本机钥匙串，不通过 iCloud 同步。服务器配置和工作区不保存密码或私钥内容。

已有凭据优先无弹窗读取，并在本次运行中复用；系统需要授权时，提供“解锁已保存的凭据…”入口。可在连接窗口清除保存的凭据。私钥文件本身不保存，设备钥匙串锁定或应用签名变化仍可能要求重新授权。

### 常用操作

1. 在左右栏点击“选择位置…”，选择本地目录或已保存的服务器；新服务器先通过“添加服务器…”保存配置。
2. 完成连接后，选择文件并拖到另一栏，或点击“复制到另一栏”。
3. 出现重名冲突时选择处理方式，在底部队列查看结果。
4. 将常用组合保存为工作区，下次从侧栏恢复。

快捷键作用于当前聚焦的文件列表：

| 快捷键 | 操作 |
| --- | --- |
| `⌘C` / `⌘V` | 复制 / 粘贴 |
| `⌘A` | 全选当前列表中的文件项目，不包含 `..` |
| `⌘⌫` | 删除所选项目，执行前确认 |
| `Shift` / `⌘` + 单击 | 连续 / 非连续多选 |
| `⌘T` | 新建双栏标签 |
| `⌘R` | 刷新两栏 |

### 当前边界

OpenTransmit 仍处于开发预览阶段，尚未提供目录差异预览、自动同步、断点续传和远程文件拖出到 Finder。本地及 SFTP 传输会尝试保留修改时间和普通读写执行权限，FTP/FTPS 尝试保留修改时间；服务器不支持或权限不足时显示元数据警告。所有者、ACL、扩展属性等尚不完整保留，不作为完整备份工具。

远程替换、重命名及递归删除不具备整项事务保证。断网或强退可能留下临时文件、备份或已完成的部分操作；如收到备份路径提示，应先检查恢复，避免直接删除。操作期间请避免其他客户端同时修改同一目标。
