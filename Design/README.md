# OpenTransmit 图标

以五菱宏光的银白色微面形象为主体，参考用户提供的 Transmit 图标的立体微缩风格。使用内置 imagegen 生成并迭代，未使用 CLI/API fallback。

- `OpenTransmit-icon-master.png`：原始生成母版。
- `../OpenTransmit/AppIcon.icon`：Icon Composer 资源，内含 1024×1024 方形图稿，由 Xcode 编译系统圆角与图标资源。
- 当前为单幅合成图稿，尚未拆分车身和背景为独立玻璃层，也未单独绘制深色外观。
- 规范参考：https://developer.apple.com/design/human-interface-guidelines/app-icons
