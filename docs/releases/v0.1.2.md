# OpenTransmit v0.1.2 测试版

OpenTransmit 是一款免费开源的原生 macOS 双栏文件传输工具。本次发布提供可直接下载安装的测试 DMG，欢迎尝鲜并反馈问题。

## 本次发布

- 优化传输速度
- 增加自动更新功能

## 欢迎反馈

请在 [GitHub Issues](https://github.com/hutengqi/OpenTransmit/issues) 提交问题，并尽量附上：

- macOS 版本、Mac 处理器类型和 OpenTransmit 版本。
- 使用的协议与服务器软件类型。
- 复现步骤、预期结果、实际结果和错误截图。

请隐藏密码、私钥、服务器敏感地址及个人文件内容。
