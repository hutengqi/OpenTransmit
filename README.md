# OpenTransmit

## 项目介绍

OpenTransmit 是一款免费开源的原生 macOS 双栏文件传输应用，使用 SwiftUI 与 AppKit 构建，以拖拽操作、明确的冲突处理和多工作区标签页，让本地与服务器之间的文件传输更直观。

- **双栏文件管理**：独立浏览目录，支持多选、复制粘贴和键盘操作；本地删除经确认后移入废纸篓，远程文件与目录支持确认后的单项及批量永久删除。
- **多协议传输**：支持 SFTP、FTP 和显式 FTPS，本地与服务器双向传输，以及两台服务器经本机中转的文件和目录传输。
- **冲突处理与队列**：同名文件可选择替换、保留副本或跳过，支持查看任务状态、取消和重试。
- **多工作区标签页**：同时使用多对文件栏，保存和编辑服务器配置，保存本地与远程目录组合及默认传输方向。
- **安全认证**：支持密码和 OpenSSH 私钥、主机指纹确认，以及可选的本机钥匙串密码与口令存储。

当前为 **0.3 多协议开发预览版**，运行要求为 **macOS 14 Sonoma 及以上**。FTP/FTPS 使用被动模式；FTPS 强制校验 TLS 证书，FTP 连接前提示明文风险。SMB 可在应用中发起系统认证、选择共享并在双栏中浏览及传输，使用 macOS 原生挂载能力。工作区可保存远程位置，SFTP/FTPS 可使用已保存密码自动恢复连接；断点续传尚未支持。
